# Learn WebGL UI

> 一个用于记录 WebGL 学习过程的项目，基于 Three.js 和 Shader 编程。

## 📚 技术栈

- **框架**: Vue 3 + TypeScript
- **UI 组件库**: Element Plus
- **3D 引擎**: Three.js
- **构建工具**: Vite
- **包管理器**: pnpm
- **代码规范**: ESLint + Prettier + Husky + Commitlint
- **Shader 支持**: vite-plugin-glsl

## 🚀 环境要求

- Node.js >= 18.0.0
- pnpm >= 8.0.0

## 📦 快速开始

### 安装依赖

```bash
# 克隆项目
git clone https://gitee.com/malu1486991775/learn-webgl-ui.git
cd learn-webgl-ui

# 安装依赖
pnpm install
```
